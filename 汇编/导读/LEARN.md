## 3. 自动批改 —— 把你的作业当考卷判 (★这套包的灵魂功能)

```bash
bash ~/asm/TOOLS/check.sh L03LOOP     # 编译 + 运行 + 和标准答案一字一句比对
bash ~/asm/TOOLS/check.sh all         # 全部自带标准答案的题目跑一遍
```

原理: 程序在无窗口 DOSBox 里跑, 屏幕输出被重定向成文件, 再和 `.EXP` 标准答案比对。
`.IN` 文件会被当成键盘输入喂给程序 —— 所以连计算器、成绩管理这些交互程序也能自动判分。

**自己写作业怎么用**: 把练习程序写成 `Mytest.ASM` (放在 LAB/ 或根目录都行):
```bash
bash ~/asm/TOOLS/check.sh Mytest      # 没有 .EXP 就把实际输出显示给你看
# 想自动比对: 把对应的 L03LOOP.EXP 复制成 Mytest.EXP 即可
```

## 5. DEBUG 速查 (实验考试必考, 提前熟)

```text
dosasm                     ← 进 DOSBox
debug L03LOOP.EXE          ← 开始调试
  r      看/改寄存器 (r ax 可改 AX)
  t      单步执行 (进了 int 21h 会迷路 —— 用 p)
  p      单步, 但把 int/call 当一步走完
  u      反汇编当前区域
  d      看内存 (d ds:0 看数据段)
  g      一路执行到结束
  q      退出
```

## 6. 报错急救表 (报错先来这查)

| 报错/现象 | 原因与解法 |
|---|---|
| `warning L4021: no stack segment` | **正常警告**, 不定义栈段就会出; 用到 push/call 的程序照 L07 定义栈段更稳 |
| `error A2019: Wrong type of register` | 常见于 `mov ss,xx` 这类: 变量名撞了段寄存器保留字(ss/cs/ds/es), 换个名 (L11 踩过) |
| `error A2053: Jump out of range` | 8086 条件跳转只能 ±127 字节! 远跳用 `jmp` 接力 (P1CALC 有注释示例) |
| `OPERAND TYPES MUST MATCH` | 两边位数不一样, 如 `mov al,bx`; 用 `byte ptr`/`word ptr` 或换寄存器 |
| `Cannot open input file` | DOS 只认 8.3 短文件名: 别用中文名/超 8 字符的名字 |
| `Undefined symbol` | 标号拼错, 或代码写在了 `end start` 后面 |
| 编译过了, 运行"跑飞"/花屏 | 忘了 `mov ah,4ch / int 21h` 结尾, 或忘了 `mov ds,ax` |
| 输出一串乱码 / 字符串后面拖尾巴 | 字符串没以 `'$'` 结尾 (9 号功能会一直打下去) |
| 调完 int 21h 数值就变了 | DOS 调用会破坏 AX! 提前保存 (L04/L05 注释里的经典坑) |
| `Divide overflow` 崩溃 | div 前忘了 `xor dx,dx`, 或者除数为 0 |
| `Phase error between passes` | 一般是上面某个真错误的连锁反应, 先把第一个错误修掉 |

## 7. 高频中断速查 (考前几天就背它)

```text
int 21h (DOS):
  01h 读一个字符(带回显)→AL      02h 打印 DL 里的字符
  09h 打印 '$' 结尾字符串(地址在 DX)
  0Ah 缓冲输入: buf[0]=容量, buf[1]=实际长度, 内容从 buf[2] 起
  2Ah 取日期: CX=年 DH=月 DL=日 AL=星期
  2Ch 取时间: CH=时 CL=分 DH=秒 DL=百分秒
  4Ch 结束程序返回 DOS

int 10h (BIOS 显示):
  02h 定位光标 (DH=行 DL=列 BH=页)
  06h 滚屏/清屏 (AL=0 时全屏刷空)

int 16h (BIOS 键盘):
  00h 读键 → AH=扫描码 AL=ASCII (阻塞)
  01h 查询有无按键 (ZF=0 表示有, ★按键不会被吃掉)

显存: B800:行×160 + 列×2 (偶地址字符, 奇地址属性: 07黑底白字 1E蓝底黄字 4E红底白字)
```

## 8. 环境与我做过的小改动 (透明说明)

- 你的 DOSBox+MASM+VS Code 环境**原样保留**, 我一个字没动。
- 升级了 `build.sh` / `run.sh`: 现在支持子目录 (LAB/L03LOOP 也能一键编), 原用法完全不变;

- 新增: `LAB/` `EXAM/` `PROJ/` 三个目录 + `check.sh` + `quiz.sh` + 本文件。
- 为什么文件名都是 `L01HI` 这种 8.3 短名? DOSBox 只认 8.3, 长名会显示成 `L01_TE~1.ASM` 找不到。
- 为什么程序里的提示文字是英文? DOSBox 控制台默认码页显示不了中文 (注释没关系, 中文注释能正常编译)。

## 9. 卡住了怎么办 (自救三连)

1. **单步 debug 看寄存器**: `run.sh 文件名` 进窗口 → `debug 文件名.EXE` → `t` 一步步走, 每一行走完 `r` 看 AX/BX/CX/FLAGS 是不是你想的值;
2. **把问题缩到最小**: 新建一个 10 行的 `T.ASM` 只放出问题的那几句, `build.sh T` 编译, 单独验证;
3. **对答案**: 每个 LAB 都是完整可跑的标准写法, 把你的和它 diff 一下 (`diff 我的.ASM LAB/L07FUNC.ASM`)。
