## 0. 先说结论: 这本书恰恰是给"不爱读书的人"写的

这不是场面话, 是作者在前言里自己说的 (pIII), 他给全书设计了五类"教学节点":

| 节点 | 是什么 | 怎么对待 |
|---|---|---|
| 知识点 | 正文小节 | **当参考手册, 卡住才翻** |
| 检测点 | 每节的随堂小测 | ★**当关卡: 做不出来不许往下走** |
| 实验 | 1~17 个上机实验 | ★**就是你们"上机题"的原型, 全做** |
| 问题分析 | 思考题 | 看一眼, 想不出来直接跳过 |
| 附注 | 拓展内容 | **第一遍全跳过** (其中两条是考试外挂, 见第 4 节) |

前言原话: **"没有通过检测点不要向下学习; 没有完成当前的实验不要向下学习。"**
—— 你看, 作者自己都说了: 这本书不是"读"的, 是**打关**的。完美匹配你的学习方式。

另外这本书讲"为什么需要汇编"的段子比我说得好: 打开 **p2 (PDF 13)** 那页,
作者让你看"用机器码写 welcome to masm 是什么体验"(一百多行 0 和 1) —— 你之前问
"为什么要有汇编/为什么这么啰嗦", 这一页就是教材层面的答案。

## 3. 书本没有、但你们考试要考的东西 (重点!)

王爽这本书前言里明说: **"不讲解每一条指令的功能"** (p III) —— 它是"讲原理"的书,
不是"指令大全"。所以下面这些**别在这本书里找**:

| 你们要考的 | 王爽书里 | 去哪补 |
|---|---|---|
| ★ **宏 MACRO / & / %** | **完全没有** (目录里没有宏章节!) | `LAB/L14MAC` (13/22 份卷子都考宏!) |
| ★ ORG / $ / EQU / TYPE / SIZE / LENGTH 系统讲解 | 只在正文零散提及 (dup 在 8.9) | `LAB/L13DIR` |
| 逐条指令细节 (DAA/CBW/CWD/IMUL...) | 前言自述"不讲" | 你们课程教材 (合工大版) 附录 / 问我也行 |

| 补码运算题 | 正文没有, **但附注 2 是专讲补码的!** | 附注 2 (p329 / PDF 340) |

## 6. 正确的打关姿势 (三步循环, 不用通读)

```
① 翻开某一章 → 只看"检测点" → 先做, 不看书
② 做不出/做错了 → 回看该检测点前后的 2~3 个小节 (别整章读!)
③ 该章结束 → 做章末"实验" → 做完 → 下一章
   卡住的检测点/实验 → 记下来, 拿来问我 (书里没附检测点答案!)
```

- **检测点没有官方答案** (这版书不附) —— 网上有流传版本但质量参差;
  你直接把检测点题目发我, 我按你们课程的判分习惯给你对答案 (顺便告诉你哪个点是你们老师爱考的)。
- 别从第 1 章硬读到第 17 章 —— 按第 1 节的大表, 考试导向的话 **只看加粗那 9 章的检测点+实验**,
  剩下的当字典。
- 这本书的正文语言其实很口语化 (作者发明了"段地址×16+偏移"这种讲法), 读起来不痛苦;
  你排斥的是"啃完整本书", 而这本书的设计就是**允许你不读完** —— 检测点没过就停在原地,
  过了就往前走, 跟打游戏一模一样。
