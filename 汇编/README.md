### LAB

每个 `.ASM` 顶部的注释就是那一课的讲义，末尾还有"练习"和"追问自己"。

| 文件 | 主题 |
| --- | --- |
| `L01HI` | 程序框架、数据段、`int 21h` 9 号功能 |
| `L02KEY` | 键盘输入、大小写转换（位运算） |
| `L03LOOP` | `loop` 与 CX、嵌套循环的坑 |
| `L04BX` | `[bx]` 寻址、`div` 拆位 |
| `L05CMP` | `cmp` 与条件跳转、打擂台找最大值 |
| `L06SORT` | 冒泡排序、双层循环 |
| `L07FUNC` | `call`/`ret`、栈、通用十进制打印（分水岭） |
| `L08NUM` | 移位指令、`xlat` 查表 |
| `L09STR` | 字符串求长、统计、转大写、反转 |
| `L10MEM` | 显存直写 `B800` |
| `L11TIME` | `int 21h` 2Ch 取时间、补零打印 |
| `L12INT` | `int 16h` BIOS 键盘中断 |
| `L13DIR` | 伪指令与内存布局、`ORG` / `$` / `TYPE` / `SIZE` / `LENGTH` |
| `L14MAC` | 宏 `MACRO` / `&` / `%` / `LOCAL` |

另外两个辅助文件：

- `L12INT.MANUAL` — 标记"这个程序必须真按键盘"，输入重定向对它无效
- `L13LIS.TXT` / `L14LIS.TXT` — MASM 生成的列表文件，左边是地址和机器码、右边是源码。搜 `inc ax` 和 `IN1` 能看到宏展开的痕迹

### TOOLS

`check.sh` 一键编译 + 运行 + 对答案，`quiz.sh` 是 24 道快问快答。**这两个脚本是为 Linux + flatpak 版 DOSBox 写的**，在你现在的 Windows + DOSBox-X 环境里跑不了，想用需要改路径和启动命令。日常开发用 VS Code 的一键链更省事。

## 怎么跑

需要 MASM（ML 6.15）+ Link + DOSBox-X。

**VS Code 一键**：Code Runner 映射 `.asm` 到一键脚本，打开源文件按 `Ctrl+Alt+N`，自动汇编、链接并在 DOSBox 里运行。

**命令行**（Windows 下）：

```bat
ml.exe /c /Zm PROG.ASM
LINK.EXE /CO PROG.OBJ,,NUL;
dosbox-x.exe -c "mount c ." -c "c:" -c "PROG.EXE" -c "exit"
```

`/Zm` 是 MASM 5.1 兼容模式，课程材料把 `start:` 写在 `proc far` 内部，不加会报 `error A2006: undefined symbol : start`。

## 两个坑

**列表文件的中文。** 仓库里的 `L13LIS.TXT` / `L14LIS.TXT` 已经处理过，是干净可读的。但**你自己生成的**列表文件会把源码注释里的中文按 GBK 一起写进去，用 VS Code 打开显示成 `绗� 14 璇�` 这种。

不影响使用——汇编生成的指令、地址、机器码全是纯 ASCII，直接搜 `inc ax`、`IN1` 照样能找到。想看中文就用记事本以 ANSI 编码打开。

自己生成新的列表文件：

```bat
masm L14MAC, L14MAC.OBJ, L14MAC.LST;
```

`/Fl` 参数（一键脚本已经带上了）也会自动生成。

**输入重定向对 `L12INT` 无效。** 它用的是 BIOS 键盘中断 `int 16h`，绕过了 DOS 输入层，必须真按键盘。

## 关于真题

`PAPERS/` 下收录了学校 2006～2022 级共 22 份试卷，分三个部分：

| 位置 | 内容 |
| --- | --- |
| `PAPERS/原始/` | 从学校公开仓库下载的 `.doc` / `.pdf` 原件，排版完整（约 1.8 MB） |
| `PAPERS/txt/` | 从原件提取的纯文本，搜索和复制方便（21 份） |
| `PAPERS/2022B.txt` | 2022-2023 B 卷的提取文本（最新那份，单独放着） |

`PAPERS/README.md` 是清单和考点频率统计，值得先看——它告诉你哪类题出现得最多。

来源是 GitHub 公开仓库 `TenMoons/AHU-CS-Repository` → 汇编语言程序设计。原件版权归学校与原出题教师，带"答案"字样的卷子尤其要注意，**仅作个人学习使用，不要二次传播或用于商业用途**。

精讲里标 `[MASM实测]` 的地方，都是把题真的敲进 MASM 跑出来的报错原文，可以自己复现。

## 文件形态说明

汇编项目的目录里常见几种同名文件，它们不是重复：

| 扩展名 | 是什么 |
| --- | --- |
| `.ASM` | 源码，要读要改的东西 |
| `.OBJ` | 汇编器产出的中间文件 |
| `.EXE` | 链接后的可执行文件，DOSBox 里能直接跑 |
| `.LST` | 列表文件，左边地址与机器码、右边源码，看宏展开必备 |
| `.EXP` | 期望输出，用来对答案 |
| `.IN` | 测试输入，重定向喂给程序当键盘输入 |
| `.MANUAL` | 标记"这个程序必须真按键盘" |

`.OBJ` 和 `.EXE` 是编译产物，本仓库不收录，需要时自己编译一份。
