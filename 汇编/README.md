# 汇编语言（AHU · 8086 课程）—— 源码与真题精讲

本目录是博客两篇汇编文章的配套材料：[《8086 汇编上手：环境与 14 课实战》](../src/content/post/汇编语言-实验环境与14课实战.md) 和 [《汇编语言（王爽·第 4 版）完整教程》](../src/content/post/汇编语言-完整教程.md)。

## 目录

| 目录 | 内容 |
| --- | --- |

| [`PROJ/`](./PROJ) | 3 个课程项目：计算器、成绩管理、电子钟，附测试输入 `.IN` 与期望输出 `.EXP` |

## 怎么跑

需要 MASM（ML 6.15）+ Link + DOSBox-X。两种方式任选：

**VS Code 一键**：Code Runner 映射 `.asm` 到一键脚本，打开源文件按 `Ctrl+Alt+N`，自动汇编、链接并在 DOSBox 里运行。

**命令行**（Windows 下）：

```bat
ml.exe /c /Zm PROG.ASM
LINK.EXE /CO PROG.OBJ,,NUL;
dosbox-x.exe -c "mount c ." -c "c:" -c "PROG.EXE" -c "exit"
```

`/Zm` 是 MASM 5.1 兼容模式，课程材料把 `start:` 写在 `proc far` 内部，不加会报 `error A2006: undefined symbol : start`。

## 用 `.IN` 喂输入

`LAB/L02KEY` 和 `PROJ/` 下的三个项目是交互式的，测试输入在同名 `.IN` 文件里，期望输出在 `.EXP` 里：

```bat
PROG.EXE < P1CALC.IN > OUT.TXT
```

然后和 `P1CALC.EXP` 逐行对比即可。注意 `L12INT` 用的是 BIOS 键盘中断 `int 16h`，绕过了 DOS 输入层，**输入重定向对它无效**，必须真按键盘。

## 关于真题

`EXAM/` 里的精讲是基于学校 GitHub 公开仓库 `TenMoons/AHU-CS-Repository` 中的试卷整理的。原始 `.doc` / `.pdf` 试卷**没有随本仓库分发**，原因有三：

- 试卷排版含大量图片和表格，纯文本提取后信息会丢失；
- 部分卷子带官方答案，转载原件的版权状态不清晰；
- 精讲里已经把每道题的题干、错误点和改法完整复述了一遍，原件只是排版更完整。

需要原件的话，去上面那个公开仓库自取。精讲里凡是标了 `[MASM实测]` 的地方，都是把题真的敲进 MASM 跑出来的报错原文，可以自己复现。

## 文件形态说明

汇编项目的目录里常见几种同名文件，它们不是重复：

| 扩展名 | 是什么 |
| --- | --- |
| `.ASM` | 源码，要读要改的东西 |
| `.OBJ` | 汇编器产出的中间文件 |
| `.EXE` | 链接后的可执行文件，DOSBox 里能直接跑 |
| `.LST` | 列表文件，左边地址与机器码、右边源码，看宏展开必备 |
| `.EXP` | 期望输出，用来对答案 |
| `.IN` | 测试输入，重定向喂给程序当键盘输入 |

`.OBJ` 和 `.EXE` 是编译产物，本仓库不收录，需要时自己编译一份。
