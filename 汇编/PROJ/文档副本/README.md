# 测试数据（可读副本）

`.IN` 和 `.EXP` 是给程序喂输入、对答案用的原始文件，这里放的是补了换行的可读版本。

原始文件的历史情况不一致，有两类：

- **P 系列和 L02KEY**：整份文件是 `0Dh`（CR）单字节分隔，一个换行符都没有。这是 DOS 时代"只回车不换行"的约定，程序按字符流读完全正确，但用编辑器打开会挤成一行。
- **EXAM 里的 .EXP**：用的是正常的 CRLF，本身没问题，放这里只是为了统一。

可读版本可以放心看，但**别直接喂给程序**——补出来的 `0Ah` 在 P 系列程序里会变成一次额外的空输入。要还原成 DOS 格式：

```bash
# CRLF -> CR，并压掉多出来的空行
perl -pe 's/\r\n|\r/\r/g' P1CALC.IN | perl -0pe 's/\r{2,}/\r/g' > P1CALC.dos
```

其实更简单：这些程序都支持交互输入，直接在 DOSBox 里手敲。

## 为什么 L12INT 没有输入文件

它用的是 BIOS 键盘中断 `int 16h`，绕开了 DOS 输入层，**输入重定向对它无效**。`LAB/L12INT.MANUAL` 这个空文件就是标记"这个程序必须真按键盘"。
