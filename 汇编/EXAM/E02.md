# 答案与解析

## 一、读程序

**1.** 输出 **2 行, 每行 3 个 `#`**。外层 BL=2 控制行数, 内层 CX=3 控制列数。
第二问: **会坏掉**。外层如果用 CX 计数, 内层 `mov cx,3` 会把它改成 3, 跑完列循环
CX 又变 0 —— 外层根本不知道自己该跑几轮了 (典型现象: 行数不对/死循环)。
纪律: **每层循环用各自的计数寄存器, 内层永远别碰外层的计数**。

**2.** call 之后 SP = **00FEH** (压入返回地址, 减 2);
push ax 后 = **00FCH**; push bx 后 = **00FAH**; pop bx 后 = **00FCH**; ret 后 = **0100H**。
(每次 push 减 2, pop 加 2, call/ret 也是暗中的一次 push/pop)

**3.** CX = **5**, push 了 **5** 次。12345 → 商 1234 → 123 → 12 → 1 → 0, 共 5 次;
每次 push 一位数字, 正好 5 位。

**4.** AL = **'C'**。xlat 查表: AL=0CH=12, 表里第 12 个字符 '0123456789ABCDEF' 数下去
(0 是第 0 个): 0,1,2,...,9,A,B,C → 第 12 个是 C。

**5.** **`ja L1` 生效**。理由: ja 是**无符号**比较, FFFFH 当无符号 = 65535 > 1, 成立;
而 jg 是**有符号**比较, FFFFH 当有符号 = -1, -1 > 1 不成立, 所以 jg 不跳。
一句话: **同一个 FFFFH, 无符号视角是 65535, 有符号视角是 -1 —— 跳转指令选错了, 结论就反了**。

## 三、编程题

**1. 找最大值** 要点: `bx = offset arr; ax = [bx]` 当擂主; 循环 4 次:
`add bx,2 / cmp ax,[bx] / jae 下一轮 / mov ax,[bx]`; 最后打印时**先存好结果再调 9 号功能**
(int 21h 会破坏 AX —— 这是全卷最大陷阱)。

**2. 大写计数** 要点:
```asm
     mov di, 0                 ; 计数器用 DI (CX 留给 loop 用)
read:
     mov ah, 1
     int 21h
     cmp al, '.'
     je  done
     cmp al, 'A'
     jb  read
     cmp al, 'Z'
     ja  read
     inc di
     jmp read
done:
     ; 打印 "count = " + DI 的值
```
   (打印一位数直接 `add dl,'0'` 就行; 还要考虑打印多位数的话用 printnum)

**3. 乘法表** 思路骨架:
```asm
     mov bl, 1                 ; BL = 外层 i (用 BL 不用 CX!)
row:
     mov cl, 1                 ; 内层 j 从 1 到 BL
     mov ch, 0
col:
     ; --- 打印 "i*j=" ---
     ; i: BL 转字符 (可能两位数, 两位数就借 print2)
     ; '*'
     ; j: CL 转字符
     ; '='
     ; 乘: mov al,bl / mul cl → AL = 积 (9×9=81 ≤ 99 两位内, 安全)
     ; 打印积 (两位以内, div 10 拆位法)
     ; 打印一个空格
     inc cl
     cmp cl, bl
     jbe col                   ; ★j <= i 就继续 (注意用的是 jbe!)
     ; 换行
     inc bl
     cmp bl, 9
     jbe row
```
   要点: 外层用 BL、内层用 CL 互不干扰; 乘积最大 81 不会溢出 8 位乘法(AL);
   `jbe col` 的内层上界是"动态的 i", 这就是它比卷一难的地方。
