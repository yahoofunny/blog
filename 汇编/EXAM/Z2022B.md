# 一、分析简答题 (40 分)

## 1. 找出下列指令的错误 (10 分)

### (1) `ADD VAR1, VAR2`  (VAR1, VAR2 都是字变量)

**错在哪**: 两个操作数**都在内存**。8086 的加法电路是"寄存器 ↔ 内存/寄存器"的,
**没有"内存 + 内存"这条指令** —— 硬件上就没有, 汇编器必须帮你拦住。

`[MASM实测]` `error A2052: Improper operand type`

**怎么改**: 借个寄存器中转 (这是汇编里最典型的"啰嗦"之一):
```asm
mov ax, VAR1
add ax, VAR2
mov VAR1, ax        ; 结果写回 (ADD 不会自动写回内存!)
```

### (2) `SUB AL, VAR1`  (VAR1 是字变量)

**错在哪**: **类型不匹配**。AL 是 8 位, VAR1 是 16 位的字变量 —— 两边"宽度"必须一致。

`[MASM实测]` `warning A4031: Operand types must match`
(有意思吧: 编译器只给**警告**, 但考卷要的就是这个错误的写法, 考试就写"类型不匹配")

**怎么改**: `sub al, byte ptr VAR1` (强转成字节取) 或把 AL 换成 AX。

### (3) `JMP LAB[SI]`  (LAB 是标号)

**错在哪**: JMP 的转移目标只有两种合法形式:
- **标号** (直接转移, 如 `JMP LAB`)
- **寄存器/内存单元** (间接转移, 如 `JMP BX`、`JMP WORD PTR [SI]`)

`LAB[SI]` 把"代码标号"和"变址寻址"混在一起 —— 标号是代码段的地址, `[SI]` 默认按数据段寻址,
汇编器直接懵了。

`[MASM实测]` `error A2044: Must be associated with data`

**考试就答**: 间接转移指令的操作数不能带位移/标号参与寻址。
(犟一下的话 `jmp word ptr cs:LAB[SI]` 能编过 —— `[MASM实测]` 通过 —— 但考试写标准答案。)

### (4) `JNZ VAR1`  (VAR1 是变量)

**错在哪**: 条件转移指令 (JNZ/JZ/JB...) 的转移目标**必须是标号**, 不能是内存变量。
"跳到地址 1 去执行"? 那不是程序该干的事。

`[MASM实测]` `error A2045: Must be associated with code`

### (5) `JMP NEAR LAB`

**错在哪**: `NEAR` 不是一个随便加的修饰词。写法应该是 `JMP LAB` (默认就近转移),
要显式声明类型得写成 `JMP NEAR PTR LAB`。

`[MASM实测]` `error A2028: Operator expected`

## 2. 伪操作错误 (6 分)

### (1) `DATA_SEG SEG`

**错在哪**: `SEG` 是"**取段地址运算符**" (`MOV AX, SEG DATA` 里的那个), 不是伪指令。
定义段用 `SEGMENT`。

`[MASM实测]` `error A2105: Expected: instruction or directive`

### (2) `MYDATA SEGMENT/DATA`

**错在哪**: SEGMENT 后面只能跟三个可选字段: **对齐 (align) / 组合 (combine) / 类别 ('class')**,
`/DATA` 什么都不是。

`[MASM实测]` `error A2105: Expected: align, combine, or 'class'`

**怎么改**: `MYDATA SEGMENT` 直接完事 (非要写类别: `MYDATA SEGMENT 'DATA'`)。

### (3) END 位置错误

```asm
MAIN_PROC PROC FAR
     ……
END MAIN_PROC          ← 错在这里!
MAIN_PROC ENDP
```
**错在哪**: `END` 是**整个源程序的最后一条语句** (告诉汇编器"代码到此为止, 入口在这"),
它后面不能再有任何东西。END 一出现, 后面的 `MAIN_PROC ENDP` 全被无视了 —— 你的过程
没闭合, 段也没闭合。

`[MASM实测]` `Open segments: CODE` / `Open procedures: MYP` (未闭合的段/过程)

**怎么改**: END 挪到最后, ENDP 在它前面:
```asm
MAIN_PROC ENDP
END MAIN_PROC          ; END 后跟"程序入口标号"
```

## 3. 移位实现乘法 (4 分)

**题目**: 把 AX、BL、DH 都乘以 8, 用 `MOV CL,3 / SHL AX,CL / SHL BL,CL / SHL DH,CL` 行吗?

**答**: **能完成** —— 左移一位 = ×2, 左移 3 位 = ×8, 三条 SHL 分别作用在三个寄存器上, 互不干扰。
`[MASM实测]` 这段序列完全合法 (0 错误)。

**但要说清条件** (得分点): 移位是**无检测的乘法**, 只有乘积不超出各自的位数能表示的范围时结果才正确
(比如 BL=40H, ×8 = 200H 超出 8 位 → 高位丢失)。另外 8086 中移位数超过 1 时**必须放 CL**,
不能写 `SHL AX,3`。

## 4. 数据定义应用题 (6 分)

```asm
LNAME    DB 30 DUP(?)      ; 偏移 0, 长 30
ADDRESS  DB 30 DUP(?)      ; 偏移 30, 长 30
CITY     DB 15 DUP(?)      ; 偏移 60, 长 15
CODELIST DB 1,7,8,3,2      ; 偏移 75, 长 5
EBUFF    DB 0              ; 偏移 80, 长 1
```

**(1) 用一条 MOV 把 LNAME 的偏移地址放入 AX**:
```asm
MOV AX, OFFSET LNAME       ; (LEA AX, LNAME 也对)
```
考点: OFFSET 取**偏移地址**, 而 `MOV AX, LNAME` 取的是**内存内容** (两个词别混)。

**(2) 用一条指令把 CODELIST 的头两个字节放入 SI**:
头两个字节是 1 和 7 → 小端序拼成一个字 = **0701H**:
```asm
MOV SI, WORD PTR CODELIST  ; ★WORD PTR: CODELIST 本身是"字节型", 要告诉汇编器取一个字
```

**(3) 让 CODELENGTH 等于 CODELIST 的实际字节长度**:
```asm
CODELENGTH EQU $-CODELIST      ; ★这一行要放在 CODELIST 定义行的"后面、EBUFF 前面"!
```
**★隐藏陷阱**: 如果写在 EBUFF 后面, `$` 已经跑到了 CODELIST+6 的位置, 算出来是 6 不是 5!
另一个不依赖位置的写法: `CODELENGTH EQU EBUFF-CODELIST` (= 5)。

## 5. 标志位表 (9 分) —— 经典送分/送命题

**初始 BX = 0FFFFH**:

| 指令 | SF | ZF | CF |
|---|---|---|---|
| `XOR BX,BX` | 0 | 1 | 0 |
| `ADD BX,8001H` | 1 | 0 | 0 |
| `SAR BX,1` | 1 | 0 | 1 |

**逐条解析**:
- `XOR BX,BX`: 任何数异或自己 = 0 → BX=0 → SF=0, ZF=1; XOR 恒把 CF 清 0。
- `ADD BX,8001H`: 0 + 8001H = 8001H。最高位是 1 → SF=1; 结果非 0 → ZF=0;
  没有产生进位 (结果是 8001H < 10000H) → CF=0。
- `SAR BX,1`: **算术右移**, 符号位复制到高位: 8001H = 1000...0001B → 移后 1100...0000B = C000H。
  SF=1; ZF=0; **CF = 最后移出去的那一位 = 原来的 bit0 = 1** → CF=1。

> 记忆口诀: **"移出去的位进 CF"** —— 不管 SHL/SHR/SAR/ROL, CF 都记录"最后离开的位"。

## 6. ORG 与内存分配 (3 分) —— 需要动手算

```asm
DATA SEGMENT
     ORG  $+20H              ; ① 当前位置往后空 20H 字节
DA1  DB   10H DUP(2,3)
DA2  DW   10H DUP(2,3)
     ORG  $+20H              ; ② 再空 20H 字节
BUF  DD   DA1,DA2
DATA ENDS
```

**手算过程** (把 $ 当成"当前偏移"一步步挪):
1. `ORG $+20H`: $ 从 0 → **20H**。
2. `DA1 DB 10H DUP(2,3)`: DUP 里 `(2,3)` 是两个字节 (2 和 3), 重复 10H 次
   → 10H × 2 = **32 (20H) 字节**。结束后 $ = 20H+20H = 40H。
3. `DA2 DW 10H DUP(2,3)`: 每个 DW 占 2 字节, 一个重复单元 = 2 个 DW = 4 字节,
   重复 10H 次 → 10H × 4 = **64 (40H) 字节**。结束后 $ = 40H+40H = 80H。
4. `ORG $+20H`: $ → 80H+20H = **A0H**。
5. **BUF 的偏移地址 = A0H**。

**答案**: DA1 分配 **32 (20H)** 字节; DA2 分配 **64 (40H)** 字节; BUF 偏移 = **A0H**。

> 想验证手感? 打开 `LAB/L13DIR.ASM` 看"实验区2"是怎么用 ORG 造空隙、
> 再打印 OFFSET 验证的 —— 同款手法。

## 7. MOV vs OFFSET (2 分)

TABLE 是偏移 0100H 单元的符号名, 里面存的内容是 0FF00H:

- `MOV AX, TABLE` → AX = **0FF00H** (取的是 **TABLE 里的内容**)
- `MOV AX, OFFSET TABLE` → AX = **0100H** (取的是 **TABLE 自己的偏移地址**)

一句话: **一个搬内容, 一个搬地址。**

# 二、程序分析题 (30 分)

## 1. 求数组平均值 —— 填空 (6 分)

```asm
FLD  DW 10,-20,30,-60,-71,80,79,56
     MOV   CX, 8
     XOR   AX, AX
 (1) MOV   SI, OFFSET FLD        ← 空①: 把 SI 指向数组开头
R1:  (2) ADD   AX, [SI]          ← 空②: 累加当前元素
     ADD   SI, 2
     LOOP  R1
     MOV   CL, 8
     IDIV  CL
     MOV   AH, 4CH
     INT   21H
```
**解析**:
- 循环里用的是 `[SI]` 和 `ADD SI,2` → SI 是数组指针, 但**没人给它初始化** → 空①
  必须是 `MOV SI, OFFSET FLD`。
- 循环体只有 `ADD SI,2` 没有累加 → 空② `ADD AX, [SI]`。
- 顺带注意: `IDIV` 是**带符号除法** (题目数据有负数, 特意选的 IDIV 而不是 DIV)。

## 2. 两数大小交换 —— 填空 (6 分)

要求: 大者进 NUM, 小者进 NUM+1。NUM 和 NUM+1 是**8 位带符号数**。

```asm
     MOV AL, NUM
     CMP AL, NUM+1
 (1) JGE  DONE            ← 空①: AL 已经≥对方, 大的已经在 NUM 里, 收工
 (2) XCHG AL, NUM+1       ← 空②: 否则交换 (换完 AL=大的, NUM+1=小的)
     MOV NUM, AL
DONE: ...
```
**得分点**:
- 题目强调"**带符号数**" → 必须用有符号跳转组 (**JGE/JL**), 用 JAE/JB 就错了 (这是题眼!)
- 相等时两个位置放谁都对, 所以用 **JGE** (≥) 而不是 JG。
- 空②的交换是这题的灵魂: `XCHG AL, NUM+1` 一条顶三条。

## 3. LP 段功能与结果 (8 分)

```asm
MOV AX,0 / MOV BX,1 / MOV CX,5
LP: ADD AX,BX
    ADD BX,2
    LOOP LP
```
BX 走的是 1, 3, 5, 7, 9 (每次 +2), 循环 5 次:
- **(1) 功能**: 求 **1, 3, 5, 7, 9 这前 5 个奇数之和** (等差数列前 5 项求和)。
- **(2) AX = 25 (19H)**; BX = 11 (0BH, 加完最后一个 9 后又 +2); **CX = 0**。

## 4. NEXT 段结果 (4 分)

```asm
MOV BX,1 / XOR AX,AX / MOV CX,5
NEXT: ADD AX,BX
      INC BX
      LOOP NEXT
```
累加 1+2+3+4+5 (每次 +1): **AX = 15 (0FH)**; 加完 5 后 BX 又 INC 一次 → **BX = 6**。

## 5. 宏展开 (6 分) —— 这就是我们 L14 课复刻的那个宏!

```asm
MSG MACRO  P1, P2, P3
    IN&P1  P2 P3
    ENDM
K=1
MSG %K,   DB,  'MY NAME'      →  展开为:  IN1  DB  'MY NAME'
MSG C, AX                     →  展开为:  INC  AX
```
**解析**:
- `&` 是**拼接运算符**: `IN&P1`, 当 P1=1 → `IN1` (数据名); 当 P1=C → `INC` (竟然是条指令!)
- `%` 是**展开运算符**: `%K` 把等值符号 K=1 先算出数值再传参;
  不写 `%` 传过去的是字面 `K`, 拼接出来是 `INK`, 名字对不上直接报错。
- 第二个调用的 P3 没给 (空), 展开成 `INC AX` 正好合法。

`[实证]` 我们的 `LAB/L14MAC.LST` 列表文件里能看到一模一样的展开过程 ——
MASM 会把你调用宏时"粘贴"出来的每一行都列出来, 打开 `LAB/L14LIS.TXT` 搜索 `inc ax` 看看。

# 三、程序设计题 (30 分) —— 三道都有可运行答案, 自己先写!

| 题 | 答案程序 | 自测命令 |
|---|---|---|
| 1. 统计 AX 中 "1" 的个数 (8分) | `EXAM/Z22B1.ASM` | `bash ~/asm/TOOLS/check.sh Z22B1` |
| 2. 求带符号数 X 的绝对值 (10分) | `EXAM/Z22B2.ASM` | `bash ~/asm/TOOLS/check.sh Z22B2` |
| 3. 1-50 中偶数累加和 (12分) | `EXAM/Z22B3.ASM` | `bash ~/asm/TOOLS/check.sh Z22B3` |

**每题的核心思想** (去看答案程序里的拆解注释):
1. **数 1 的个数**: `ROL` 把最高位转进 CF, 看 CF 计数; 注意 **CX 要存结果, 循环次数就
   不能再用 CX** —— 换 BX 数 16 次。这题考"标志位 + 寄存器规划"。
2. **绝对值**: `CMP AL,0` **碰一下标志位** → `JNS` 决定要不要 `NEG`。
   **★隐藏考点**: X = 80H (-128) 时会溢出 (NEG 后还是 80H) —— 老师爱追问这个。
3. **偶数和**: BX 步长 2 直接走偶数, 累加到超过 50 为止; 结果 650 **超过 255, RESULT
   必须用 DW** —— 这种细节就是拉开分差的地方。
