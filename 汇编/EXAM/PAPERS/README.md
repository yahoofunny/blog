## 三、建议用法 (三步)

1. **第一步**: 做 `2022-2023 B卷` (最新, 最有代表性) → 对 `../Z2022B.md` 精讲,
   每道错题顺着"去哪练"那一列回去练 —— 这一步解决 60% 的问题。
2. **第二步**: 做 `2012A含答案` 和 `11级期中含答案` 两张卷子 (题型最全的两张),
   注意它们比 2022 卷**多考两样东西**: 判断题 和 DEBUG 实验题。
3. **第三步**: 老卷子 (09/10级) 当加练, 只做"读程序写结果"和"程序填空"两个大题
   (这类题年份越老越简单, 用来练手速)。

## 四、注意事项

- 老卷子的答案偶有笔误 (比如我们实测发现 2012A 里 `$` 的取值口径和真实汇编器差了 1,
  详见 `LAB/L13DIR.ASM` 的注释) —— **考卷答案和汇编器实测冲突时, 考试按考卷口径,
  实验按实测, 两个都记住**。
- `txt/` 里是用 antiword 提取的文本, 有些表格/图形排版会丢, 拿不准就开 `原始/` 里的原件
  (PDF/doc 都能直接打开看)。
- 这些小卷子都没有"考纲"意义, 只反映出题习惯 —— 真正稳的做法还是把 `LAB/` 的 14 个
  例子跑熟 + 真题练手。
