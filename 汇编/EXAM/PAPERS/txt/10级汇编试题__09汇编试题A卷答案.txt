01  子程序和宏的区别是什么？

02  段寄存器的作用是什么？ 请分别写出四个段寄存器和名称。
    段寄存器的作用是专用于存储器寻址，用来直接或间接地存放段地址。DS：数据段寄
存器、CS：代码段寄存器、ES：附加段寄存器和SS：堆栈段寄存器。

   为标志寄存器，又称程序状态寄存器。它是存放条件码标志、控制标志和系统标志的
寄存器。

DATA  ENDS

    ASSUME  CS:CODE , DS:DATA

        PUSH  DS
        SUB   AX,   AX

        LOOP   LP2
       DEC   DI
       JNZ   LP1
       RET
MAIN  ENDP
CODE  ENDS
    END  START

七、编写程序（本题25分）
     编制一个汇编程序，求首地址为ARRAY的50个非零无符号字数组中最大偶数，并把
 它存放在AX寄存器中。如果数组中无偶数，则AX中置0。
  解：
  datarea  segment
    ARRAY  dw  50  dup(?)

  Datarea  ends                            （3分）

  Code   segment

  Main   proc  far

     Assume  cs:code, ds:datarea
  Start:
       Push  ds

       Sub   ax,ax

        Push  ax
        Mov   ax,datarea
        Mov   ds,ax                       （3分）
        Mov   SI,0
        Mov   cx,50
        Mov   ax,0                         （2分）
Next:  Mov   bx,ARRAY[SI]
        Mov   dx,bx
        Sar    bx,1
        Jc     L1
        Cmp   ax,dx
        Jae    L1
        Mov   ax,dx                        （10分）
L1:    Add   SI,2
       Loop  Next                         （5分）
        Ret

Main   endp                               （1分）

Code   ends
      End  start                           （1分）
