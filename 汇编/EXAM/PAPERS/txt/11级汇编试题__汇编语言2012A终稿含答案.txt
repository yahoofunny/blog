  （6）MOV [BP+2],5 指令是合法的。(×)

  （8）MOV  BX,[SI/2]是合法的。(×)

  （10）XOR  BL，0FH可以使BL中的低四位变反，高四位不变。(√)

六、程序设计题（每小题9分，共18分）


1.
   编写一程序，将STRS中的9个字节按相反次序存放到BUF中。（即BUF的首字符为‘I’）
   DATA  SEGMENT
        STRS DB‘ABCDEFGHI’
        BUF DB  9  DUP (?)
   DATA  ENDS

2．编写一个宏定义founds                                                MACRO
buff,char,length。查找某字符串中是否有指定的某个字符，其中参数buff为字符串，
char为指定的某个字符,
length为串的长度。再编制程序，使用你定义的宏指令founds对数据段中的字符串MYST
R查找空格符（20H）,若找到就显示字符‘Y’，否则显示字符‘N’。（显示部分不要编入宏
定义）

1.
CODE    SEGMENT
        ASSUME CS:CODE,DS:DATA
START:
        MOV  AX,DATA
        MOV  DS,AX
        MOV  CX,9
        LEA  SI,STRS+8
        LEA  DI,BUF         ；以上初始化4分
NEXT:   MOV  AL,[SI]
        MOV  [DI],AL
        DEC  SI
        INC  DI
        LOOP  NEXT
        MOV  AH,4CH
        INT  21H
CODE    ENDS
        END  START           ；以上循环5分









2.
founds MACRO  buff,char,length
        MOV  CX,LENGTH
        LEA  DI,BUFF
        MOV  AL,CHAR
        CLD
        REPNE  SCASB
        ENDM                         ；以上宏定义4分
DATA    SEGMENT
        MYSTR  DB ‘XXXXXXXXXX’
        LEN=$-MYSTR
DATA    ENDS


CODE    SEGMENT
        ASSUME CS:CODE,ES:DATA
START:
        MOV  AX,DATA
        MOV  ES,AX
        founds  MYSTR,20H,LEN         ；以上宏调用2分
        JZ   YES
        MOV  DL, ‘N’
        JMP  EXIT
YES:    MOV  DL,’Y’
EXIT:   MOV AH,2
        INT  21H
        MOV  AH,4CH
        INT  21H
CODE    ENDS
        END  START                   ；以上显示3分
