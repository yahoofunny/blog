# DEBUG 上机题专项 (你们历年卷子里 16/22 份都考它!)

> 你们学校的实验题/上机题长这样 (2012A 原题):
> "用 DEBUG 调入 PROG.EXE 后…… 列出上面程序的 DEBUG 命令是( U )。
>  CS 的值为( 4321 )。BUFF 的段地址是( 1746 )。……"
> 这部分的分数非常好拿 —— 因为所有答案都能在 DEBUG 里**当场拿出来看**。
> 本练习单给你 10 个任务, 每个都基于我们 LAB 里的程序, **动手做完 = 上机题满分**。

---

## 0. 先用 1 分钟过一遍命令 (考卷也直接考这个)

| 命令 | 干什么 | 考卷常见问法 |
|---|---|---|
| `U [地址]` | 反汇编, 把机器码翻译成指令 | "列出程序的命令是?" |
| `R [寄存器]` | 看/改寄存器 (r bx 改 BX) | "修改 BX 的值用什么命令?" |
| `T [=地址] [条数]` | 单步执行 (跟到 int 21h 里会迷路) | "T=100 后 IP=?" |
| `P` | 单步, 但把 int/call 当一条走完 | "单步进 int 21h 用什么?" |
| `D [地址]` | 看内存 (D 1746:0) | "查看 BUFF 字符串用什么?" |
| `E 地址 值...` | 改内存 | — |
| `A 地址` | 从内存开始汇编指令 | — |
| `G [=起点] [断点]` | 连续运行到断点 | "从头运行停在 RET 处用什么?" |
| `Q` | 退出 DEBUG | — |

**怎么进 DEBUG** (任选):
```bash
bash ~/asm/run.sh LAB/L01HI     # 弹出窗口跑完程序后, 停在 DOS 提示符
# 然后在窗口里敲:
debug L01HI.EXE
```
或者终端里 `dosasm` 进环境后自己 `cd LAB` 再 `debug`。

## 1. 十个任务 (做完上机题就是送分)

全部用 `LAB/L01HI.EXE` 和 `LAB/L07FUNC.EXE` 练 (先 `run.sh` 编出来)。

**任务 1 (U 命令)**: `debug L01HI.EXE` 进去后敲 `u`, 看看开头几条指令。
> 答案: 应该是 `MOV AX,xxxx` / `MOV DS,AX` / `MOV DX,xxxx` / `MOV AH,09` / `INT 21`。
> **xxxx 是 data 段的段基址, 每次链接都可能不一样** —— 考卷里问你具体数字时, 要写你屏幕上看到的实际值。

**任务 2 (R 命令)**: 敲 `r`, 记下此时 CS、IP、DS、AX 的值。
> 答案: CS:IP 是第一条指令的地址 (通常是 xxxx:0100); **DS 此时还不指向数据段**
> (它指向 PSP 附近) —— 这正是程序里那句 `MOV AX,DATA / MOV DS,AX` 存在的原因!
> 考卷经典问法: "执行完前两条指令后 DS 变成多少?" → 单步跟一下就知道。

**任务 3 (T 单步)**: 敲 `t` 两次, 再敲 `r` 看 DS 的变化。
> 答案: 执行完 `MOV AX,DATA` 后 AX = data 段基址; 执行完 `MOV DS,AX` 后 **DS 变成同一个值**。
> 这就是"段地址要经 AX 中转"的现场直播。

**任务 4 (D 看内存)**: 敲 `d ds:0`, 在内存里找 `'Hello World!$'` 的字节。
> 答案: 应该能找到 `48 65 6C 6C 6F 20 57 6F 72 6C 64 21 24`
> ('H'=48, 'e'=65, ... ' '=20, '!'=21, '$'=24)。
> 考卷经典问法: "BUFF 的段地址/偏移地址是多少?" → 段地址 = DS 的值, 偏移用 `d ds:0 往后数`。

**任务 5 (T 遇到 INT 用 P)**: 一直 `t` 到 `INT 21H` 那一条, 用 `p` 走它, 看屏幕出现 Hello World。
> 答案: 注意区别 —— **`t` 跟进 int 21h 会跑到 BIOS 代码里, 用 `p` 让 DOS 一口气干完**。
> 考卷经典问法: "单步执行 int 21h 应该用哪个命令?" → **P**。

**任务 6 (R 改寄存器)**: `r cx` 输入 `3` (把 CX 改成 3), 或者 `r ip` 输入 `100` 让程序跳回开头。
> 答案: 格式就是 `r 寄存器名`, 然后输入新值。考卷: "修改 BX 用什么命令?" → `R BX`。

**任务 7 (G 断点运行)**: 敲 `g =100 10e` —— 从 100 运行, 停在 10E 处 (断点)。
> 答案: `g =起点 断点`。考卷: "从头运行程序使其停在 RET 指令处" → `G =100 10F` (地址看实际值)。

**任务 8 (E 改内存, 最好玩)**: `e ds:0 'J'`, 把 Hello 的 H 改成 J, 然后 `g` 跑完程序。
> 答案: 屏幕上变成 **Jello World!** —— 改一个字节, 换一个世界。
> 考点: 要改的是**字符的 ASCII 码**, E 后面可以写 'J' 也可以写 4A。

**任务 9 (栈与 CALL)**: 换 `debug L07FUNC.EXE`。在 `CALL PRINTNUM` 那一句上,
先用 `r` 记下 SP, 然后 `t` 进去 (进到子程序), 再 `r` 看 SP。
> 答案: SP 减 2 (压入了返回地址); `d ss:sp` 看栈顶就是那个返回地址
> (低位在前, 小端序!)。再用 `p` 走完 RET, SP 加回来。
> 这就是 t/p 之外的送分题: "call 执行后 SP 怎么变? 栈顶是什么?"

**任务 10 (综合, 模仿考卷原题)**: 对 `L03LOOP.EXE`:
(1) 用一条命令看开头的反汇编 → `U`
(2) 看 CS 的值 → `r` → 屏幕上 xxxx:0100 里的 xxxx
(3) 从头运行到结束 → `G`
(4) 把某条指令所在单元的机器码改一个字节 (比如把 `MOV DL,41` 的 41 改成 42),
    再运行, 观察输出从 `A` 变成 `B` → `E 地址 42`

## 2. 考试速答卡 (直接背这 8 条)

1. 反汇编 → `U`
2. 看/改寄存器 → `R` / `R 寄存器名`
3. 单步 → `T`; 跳过 int 21h 单步 → `P`
4. 看内存 → `D 段:偏移` (如 `D 1746:0`)
5. 改内存 → `E 地址 新值`
6. 连续运行到断点 → `G =起点 断点` (如 `G =100 10F`)
7. "T=100 执行一条后 IP=?" → 100 + 第一条指令的字节长度 (看 U 命令里下一条的地址, 别背)
8. "程序的功能是什么?" → 看 int 21h 功能号 + 字符串: 09h 打印 / 01h 读字符 / 4Ch 结束

> 记住一个真理: **DEBUG 题的答案不用背, 全是"你敲一下就能看到的"**——
> 考场上 (如果是机考) 就这么干; 笔试卷就把上面 8 条背掉, 覆盖所有考过的问法。
