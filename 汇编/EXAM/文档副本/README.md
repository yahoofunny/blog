# 模拟卷与真题答案程序的测试数据（可读副本）

补了换行的版本，方便直接看。原始文件的换行情况见 [`../../PROJ/文档副本/README.md`](../../PROJ/文档副本/README.md)。

| 文件 | 对应程序 | 期望输出 |
|---|---|---|
| `E01P1.IN` | `E01P1.ASM` | 输入若干字符，程序分类打印 |
| `E01P1.EXP` | `E01P1.ASM` | 分类结果 |
| `Z22B1.EXP` | `Z22B1.ASM` | `count(1234h) = 5` / `count(0FFFFh) = 16` |
| `Z22B2.EXP` | `Z22B2.ASM` | `X = -58,  |X| = 58` |
| `Z22B3.EXP` | `Z22B3.ASM` | `sum(2+4+...+50) = 650` |

`Z22B1~3` 的输入是写死在程序里的常量，只有 `.EXP` 没有 `.IN`。
