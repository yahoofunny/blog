这里是 mome.bingtao.xyz 那层皮的源码 —— 把这个博客的皮肤，搬到了 Ech0 上。

这些文件只是一层皮肤 —— 拿它当不了网站。

Ech0（Go + Vue 写的单人微博客）是要自己找台服务器跑起来的： mome.bingtao.xyz 就跑在一台自建服务器上。 这套主题只是往它的「自定义 CSS / 自定义 JS」里塞的两段文本， 不含 Ech0 本身，也不含任何后端。

所以想用的话，先去下面两个地方把 Ech0 装起来，再回来拿这里的文件。

目录里有什么

custom.css构建产物 —— 粘贴到 Ech0 面板「自定义 CSS」 custom.js构建产物 —— 粘贴到 Ech0 面板「自定义 JS」 src/tokens.css色值源码（改颜色改这里） src/tail.css规则源码（第 3 节往后的所有样式） src/build.pytokens + tail → custom.css README.md同一份说明的 Markdown 版

custom.css 别手改，它是生成的。 python src/build.py 可以重新构建。

装法（四步）

  1. 先有一台服务器、一个跑起来的 Ech0。 见上面那两个链接。
  2. 字体。 把 oswald-var.woff2、courier-prime-400.woff2、 courier-prime-700.woff2 放到你站点的 /fonts/ 下 （三份都是 SIL OFL 1.1）。放别处就用 build.py 带上路径重新构建。
  3. 注入。 面板 → 系统设置 → 把 custom.css 和 custom.js 的全文分别粘进「自定义 CSS」「自定义 JS」，保存、刷新。
  4. 换成你自己的。 本目录这两份是本博客在用的那一版， 地址写死成了 bingtao.xyz。改 custom.js 顶部的 CONFIG：
particleUrl: '/bg-particle/index.html',          // 粒子壁纸页面
home:        { href: '/', icon: '/pacman.svg' }, // 左上角那个标志
themeIcons:  { light: '/off.svg', dark: '/on.svg' }, // 右上角开关灯
nav:         [ ... ],                            // 中间那几栏
sourceUrl:   '',                                 // 侧栏源码入口（见下）

几件要知道的事

  • 没有 /en/ 路径。 Ech0 的语言是客户端状态， 不是路由。顶栏那个 中 / EN 药丸是去点它原生菜单，点完当场变、 不用刷新；要分享英文链接就用 ?lang=en。
  • 顶栏是这套主题加的，不是 Ech0 自带的。Ech0 原生的主题键和 语言键被脚本打标记藏掉了。
  • 图标得是深色线条的 SVG —— 暗色下脚本会给它加 invert(1) 翻白。
  • 只有明暗两态。 Ech0 原生是 light → sunny → dark 三态循环，这里接管成了干净的两态。
  • sourceUrl 请填上。 Ech0 和这套主题都是 AGPL-3.0，§13 要求「通过网络与它交互的用户能拿到对应源码」—— 填成你自己那份主题仓库的地址，侧栏会多出一个 SOURCE 入口。
