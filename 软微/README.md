## 速览

- **初试（01-04 方向）**：政治 + 英语一 + 数学一 + 408，统一划线、统一排名。
- **2026 院线**：378（单科 55/55/90/90）；近六年 350 → 350 → 365 → 380 → 357 → 378。
- **复试**：初试 60% + 复试 40%，60 分及格线；考生实录为笔试（手写代码）+ 面试，备考推荐刷力扣热 100（至少 2 遍）与《代码随想录》。
- **学费学制**：3 年，共 9 万元；大兴校区。
