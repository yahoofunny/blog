> 目标 6–7 分。原则：**结构 > 词汇，自然 > 华丽，答所问 > 炫技**。风格基准：前考官 Simon——短句、想法第一、具体细节。可配合本系列雅思写作笔记（大作文 / 小作文）与口语题库使用。

## 一、写作 Writing（60 分钟）

先写大作文：**Task 2 用 40 分钟 ≥250 词** → Task 1 用 20 分钟 ≥150 词。

### Task 2 万能骨架（四类题型通用）

> ① 开头（2 句）
> <span style="color:#e5484d">While it is true that [反方/另一面], I believe [你的立场], because [一句核心理由].</span>
> ★ 立场必须覆盖题目所有关键词（如 All / young people）
>
> ② 主体段 ×2（每段 10 分钟）= PEEL
> Point 一句论点 → Explain 为什么成立 → Example 具体例子 → Link 拉回题目关键词
> （Example 是 6.5 分发动机：数字/城市/研究/机构，拒绝 "many people"）
>
> ③ 结尾（2–3 句）换词重述立场 + 判断句
> <span style="color:#e5484d">In conclusion, although [让步点] are real, …far more than it costs…</span>

**四类题型一句变式**

| 题型 | 变式 |
| --- | --- |
| 观点题 | Body 2 = 承认反方 + 反驳 |
| 讨论题 | 两边各讲一段（必须公平），结尾给己方观点 |
| 问题解决 | Body 1 两个问题 → Body 2 一一对应方案 |
| 利弊题 | 详写占优方，让步段认劣势，结论明确 outweighs |

**连接词银行（跟内容绑定，避免模板腔）**
<span style="color:#3b82f6">The most immediate benefit is that…</span> <span style="color:#3b82f6">This is compounded by…</span> <span style="color:#3b82f6">The key point, however, is that…</span> <span style="color:#3b82f6">This is not to say that…</span> <span style="color:#3b82f6">A case in point is…</span> <span style="color:#3b82f6">On balance,</span>

**自检 30 秒**：立场清晰？每段有具体例子？回应所有关键词？≥250 词？无逗号粘连句？

### Task 1 万能骨架

> ① 改写题目（禁抄原句）→ ② Overview 2 句（第二段，讲整体不讲数字）→ ③ 正文分组讲数据
> 无结尾段；永不写观点

**Overview 句式**：<span style="color:#e5484d">Overall, [X] rose steadily over the period, while [Y] remained relatively stable.</span> / <span style="color:#e5484d">The most striking feature is that…</span>

**趋势词**：升 <span style="color:#3b82f6">rise</span>/<span style="color:#3b82f6">increase</span>/<span style="color:#3b82f6">climb</span> · 大升 <span style="color:#3b82f6">surge</span> · 降 <span style="color:#3b82f6">fall</span>/<span style="color:#3b82f6">drop</span>/<span style="color:#3b82f6">decline</span> · 稳 <span style="color:#3b82f6">remain stable</span>/<span style="color:#3b82f6">level off</span> · 波动 <span style="color:#3b82f6">fluctuate</span> · 峰 <span style="color:#3b82f6">peak at</span> · 谷 <span style="color:#3b82f6">reach a low of</span>；程度副词 <span style="color:#3b82f6">slightly</span> → <span style="color:#3b82f6">gradually</span> → <span style="color:#3b82f6">steadily</span> → <span style="color:#3b82f6">considerably</span> → <span style="color:#3b82f6">significantly</span> → <span style="color:#3b82f6">sharply</span> → <span style="color:#3b82f6">dramatically</span>；比较 <span style="color:#3b82f6">roughly twice as many…as</span> <span style="color:#3b82f6">by contrast</span> <span style="color:#3b82f6">overtook</span>；未来 <span style="color:#3b82f6">is projected to</span>。流程/地图题全篇被动语态（<span style="color:#3b82f6">is fed into</span> <span style="color:#3b82f6">was demolished</span> <span style="color:#3b82f6">converted into</span>）。

## 二、口语 Speaking（11–14 分钟）

考场节奏：Part 1 约 4–5 分钟（2–3 组话题、约 11–14 问）→ Part 2 给卡后 1 分钟准备、陈述约 2 分钟 → Part 3 就卡片主题抽象追问约 4–5 分钟。

### Part 1 —— 三句公式（每题约 15 秒）

1. 直接回答（Yes / Not really + 核心句）
2. 理由或细节（because… / 一个具体场景）
3. 补充延伸（but… / when I… / for example…）

> 绝不只答 Yes/No；2 句及格，3 句良好。

### Part 2 —— 叙事四步

1. 首句定位：<span style="color:#e5484d">I'd like to talk about…</span>（WHO/WHAT + 时间地点）
2. 按卡片 4 个提示点各走 2–3 句（**提示卡顺序就是你的提纲**）
3. 结尾收感受：<span style="color:#e5484d">Honestly, what I remember most is…</span>
4. 准备 1 分钟只写 4 个单词提示，不写句子

### Part 3 —— 3–4 句公式

观点句 → 理由句 → 例证/对比句：<span style="color:#3b82f6">I'd say that…</span> <span style="color:#3b82f6">It depends on…</span> <span style="color:#3b82f6">The reason is that…</span> <span style="color:#3b82f6">whereas</span> <span style="color:#3b82f6">especially when…</span> <span style="color:#3b82f6">like when I…</span>

### 口语四条底线（6 分保命，7 分加分）

1. **答所问**——考官问什么答什么，不背准备好的题
2. 允许想 1–2 秒（<span style="color:#3b82f6">That's a good question.</span>），但一次就够
3. 自然词汇 > 背错的高级词
4. 语法盯三样：过去式、第三人称单数、可数/不可数

> **考前速记**：作文＝开头让步式 + PEEL + 具体例子 + 换词结尾；小作文第二段必须有 Overview（缺失封顶 5 分）。口语＝P1 三句 | P2 按卡四点走 | P3 观点+理由+例子。
