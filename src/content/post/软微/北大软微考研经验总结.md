## 一、样本画像

25 篇经验贴覆盖的样本谱系很宽，核心结论是：**决定结果的不是备考总时长，而是执行密度与取舍是否清晰**。

| 维度 | 样本 |
| --- | --- |
| 备考周期 | 75 天（推免失利转考）、5 个月、常规一年、大二起长线——全部上岸 |
| 背景 | 科班（北航 / 211 / 双非）、零基础跨考（理科 / 电子信息）、二战 |
| 初试总分 | 382 – 420，26 届高分段集中在 400+ |
| 数学一 | 有具体分数的样本普遍 **134 – 147**，是拉开差距的核心科目 |
| 408 | **118 – 135**，120 上下即可支撑 400+ 总分 |

> 阅读提示：单篇经验帖是个体样本，不要照搬时间表；多篇互相印证的"共识"才值得当作方法论。

## 二、各科经验共识

### 数学一

- **以练代听**：多篇高分帖方法高度一致——限时套卷 + 逐题复盘，听课占比压到最低。
- **成套计时训练**是主线：真题反复刷，错题归因到「知识盲区 / 计算失误 / 读题问题」三类。
- **写完整解题步骤**（"走吧"帖的专门提醒）：大题步骤分与备考内容无关，纯粹是呈现问题，考前要刻意练习。
- 二战样本（YeAh）：数学从 91 提到 146，靠的同样是"套卷 + 复盘"的执行密度。

### 408

- **跨考 / 零基础共识路径：王道教材多轮推进**——先解决"会不会"（多轮滚动），再解决"写不写得清楚"。
- 科班样本强调**算法题的思路与代码表达规范**（"走吧"帖），408 大题表达不清是常见失分点。
- 真题反复刷：有帖子真题刷 4 遍以上、软微回忆版刷 5 遍以上（小红书"柠檬"帖）。
- 408 单科 118—135 即可支撑总分 400+，不必追求单科极致。

### 英语一

- 词汇全程滚动 + 真题精读是共识；作文用模板 + 真题演练。
- 高分样本（virtual 小满，英一 93）：词汇是底线，阅读靠真题精读，作文提前准备而非临场发挥。
- 初试英语一不含听力口语；复试外语环节以口语问答为主。

### 政治

- **有明确的下限时间：不能晚于 11 月中旬开始**（znvu 帖的直接警告）。
- 共识打法：前期不投入，9—10 月选择题强化，11—12 月冲刺背诵 + 主流押题卷。
- 政治是投入产出比最低的科目，砍时间时优先砍它——但要在 11 月中旬前启动。

## 三、时间规划

| 节奏 | 适用 | 要点 |
| --- | --- | --- |
| 全年（3—12 月） | 科班 / 一战常规 | 3—6 基础（数学 + 408 教材），7—9 强化（习题册），10—11 真题套卷，12 冲刺（政治背诵 + 错题） |
| 5—6 个月 | 基础好 / 时间紧 | 直接进入强化与真题阶段，砍掉低性价比环节（"对方正在输入"：5 个月 401，数学 147） |
| 极限（75 天） | 特殊情况 | 鸽子鸽：把有限时间全部压在得分项上，砍政治听课、砍 408 教材细节，主打真题与高频考点 |

> 三处反复出现的提醒：① 每天有效学习时长（而非坐在桌前的时间）才是关键；② 不要用"看视频"替代"做题"；③ 计划要留复盘与休息日。

## 四、复试经验

**规则**（以 2026 年为准，每年以当年细则与邮件通知为准）：

| 要素 | 内容 |
| --- | --- |
| 权重 | 初试 60% + 复试 40%：加权总成绩 ＝ 初试权重 × 初试 4 门总成绩/5 ＋ 复试权重 × 复试成绩 |
| 合格线 | 复试百分制，**60 分及格，不及格不予录取** |
| 形式 | 官方：以综合面试为主（含外语能力）；考生实录：近年多含笔试（算法 / 机试题）＋ 面试 |

**流程**（考生实录归纳）：成绩公布（2 月下旬）→ 复试通知邮件（3 月中旬）→ 资格审查与材料寄送 → 复试（2026 年为 3 月 25 日起，大兴校区）→ 拟录取公示（4 月初）。

**经验共识**：

- 笔试 / 机试：按分类刷题（《代码随想录》被多篇推荐），覆盖模拟、贪心、分治、动态规划等；题型逐年变化（出现过编辑距离 DP、手撕神经网络设计）。
- 面试：英语口语问答 + 专业课基础 + 项目经历复盘，自我介绍要能把项目讲清楚。
- **最硬的教训**：2026 年有 412 分考生复试 61.6 分落榜，也有 378 分压线考生复试 90+ 逆袭——**初试定资格，复试定结果**，复试准备要与初试同等重视。
- 复试材料（成绩单、个人陈述、诚信承诺书等）注意截止时间；通知全部走邮件，务必每天查收。

## 六、避坑清单

1. **付费辅导要货比三家**（MMMM 帖专节）：识别"每隔几句话一个淘宝链接"式付费推广；评论区只显示筛选后评论的要警惕；退费按剩余课时计算，维权成本高。
2. **焦虑贩卖**："11408 一战学不完""九月肯定来不及"——75 天样本证明周期不是决定因素，执行力才是。
3. **政治启动过晚**（11 月中旬是底线）；以及"看视频 = 复习"的错觉。
4. **书写失分**：数学大题不写完整步骤、408 算法题思路与代码表达不清——这是与备考内容无关的纯失分。
5. **低估复试**：40% 权重 + 60 分硬线，高分翻车是真实存在的。
